
# Git Basics for Beginners

Git helps developers track changes and collaborate on projects.

## Common Git Commands

- `git status` - Check the current working tree status.
- `git branch` - List existing branches.
- `git switch -c branch-name` - Create and switch to a new branch.
- `git add .` - Stage changes for a commit.
- `git commit -m "message"` - Record staged changes.
- `git push` - Upload commits to a remote repository.

## Contribution Workflow

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Make and test your changes.
5. Commit and push your changes.
6. Open a pull request for review.
